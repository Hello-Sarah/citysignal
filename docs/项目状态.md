## 运维备忘

**两条生效路径不同，别搞混：**
- 邮件相关代码 → 保存即生效（触发器绑定 HEAD）
- 网页相关代码 → 必须发布新版本：部署 → 管理部署 → 编辑 → 版本「新版本」→ 部署

**Apps Script Web App 首屏约需 10 秒**，白屏不等于故障。

**危险操作**：编辑器函数下拉框里 `sendWeeklyEmail` 紧邻 `createWeeklyTrigger` 上方，
选错点「运行」会立刻发出一封邮件。运行任何函数前先确认下拉框内容。
