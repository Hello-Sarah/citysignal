# 数据规范 · Events 表

数据源是一张 Google Sheet 的 `Events` 标签页。**第 1 行是表头，列顺序固定**，Apps Script 按表头名取值，
所以列名不能改，顺序也不要调（`readAllEvents_()` 依赖表头映射，但下游的粘贴流程依赖顺序）。

| # | 列名 | 必填 | 取值 | 说明 |
|---|------|------|------|------|
| A | `City` | ✅ | 见「城市」一节 | 一级逻辑分区。不同城市各自成期，互不影响 |
| B | `WeekId` | ✅ | `YYYY-MM-DD` | 该期的**周三**日期。同城市同一期所有行相同 |
| C | `Zone` | ✅ | **取值取决于 City**，见下 | 二级分区，渲染成大标题 |
| D | `SubGroup` |  | 见下 | 三级小节标题 |
| E | `Category` | ✅ | `吃` / `展` / `玩` / `演` / `喜剧` / `音乐` / `讲座` / `读书` / `集市` / `文化` | 车票左联上的小标签 |
| F | `Title` | ✅ | 自由文本 | 活动名 |
| G | `DateInfo` |  | 自由文本 | 人读的日期时间，如 `09.05–07 10am–5pm`。**不做日期解析，纯展示** |
| H | `Location` | ✅ | 自由文本 | 地址或场馆名 |
| I | `Status` | ✅ | `已核实` / `场地已核实` / `未核实` | 核实等级，决定徽章颜色 |
| J | `PriceInfo` |  | 自由文本 | 如 `免费·无需预约`、`$8.24起` |
| K | `MapLink` |  | `https://` 开头 | Google Maps 链接。**只放链接**，联系方式放 Note |
| L | `Note` |  | 自由文本 | 备注 + 信源，如 `presidio.gov官方` |
| M | `Pick` |  | 空 或 任意非空（建议 `★`） | 非空 = 精选推荐，页面上金色高亮，邮件里优先列出 |

> **简繁两种写法都接受。** 界面已改为繁体，但表里的历史数据是简体。
> 代码在读取时对 5 个枚举列（`City` / `Zone` / `SubGroup` / `Category` / `Status`）
> 做简→繁映射，所以 `已核实` 和 `已核實` 是等价的，表格不需要批量改。
> **自由文本列不做任何替换**——正文要转繁体得整段过 OpenCC，逐字替换会把活动名改坏。


## 城市（City）

`City` 是最外层的逻辑分区。**每个城市有自己独立的期次序列**——
三藩市出了新一期，不会让香港的页面跳到一个空日期上。

| City | 页面 slug | 合法 Zone |
|------|-----------|-----------|
| `三藩市湾区` | `sf` | `三藩市市内` / `湾区市外` / `华人社群活动` |
| `香港` | `hk` | `港岛` / `九龙` / `新界` |

> ⚠️ **Zone 是城市耦合的字段。** 香港没有「湾区市外」，湾区没有「港岛」。
> 校验器按 `CITY_ZONES` 查表校验，这张表必须和 `Code.gs` 里 `CONFIG.CITIES` 的
> `zones` **手工保持一致**——两处不同步是这个 schema 目前最容易出的问题。

加一个新城市：`CONFIG.CITIES` 加一项 + 校验器 `CITY_ZONES` 加一项，
不需要改任何渲染代码。

## SubGroup 取值约定

| City | Zone | SubGroup 格式 | 例 |
|------|------|--------------|-----|
| 三藩市湾区 | `三藩市市内` | 与 Category 同名 | `吃` `展` `玩` `演` |
| 三藩市湾区 | `湾区市外` | `玩·地名` / `演·地名` | `玩·Millbrae` `演·San José` |
| 三藩市湾区 | `华人社群活动` | 地区 | `三藩市` `半岛` `南湾` |
| 香港 | `港岛` / `九龙` / `新界` | 与 Category 同名 | `吃` `展` `玩` |

香港不设「华人社群活动」分区：整座城市都是华人社群，这个分区在那里没有区分度。
**分区的意义是帮读者定位，不是套用同一个模板。**

> ⚠️ **不要把活动名填进 SubGroup**。`renderZone_()` 把 SubGroup 当小节标题渲染，
> 填成活动名会导致每个活动上方印一遍自己的标题。这是项目早期真实踩过的坑。

## Status 的语义（详见 docs/功能文档.md 的验证方法论）

| 值 | 含义 | 徽章样式 |
|----|------|---------|
| `已核实` | 官方/政府信源确认（.gov、场馆官网、主办方官网或其自有票务页） | 绿底白字 |
| `场地已核实` | 地址属实，但活动细节只有聚合站等二手来源 | 绿字绿边框 |
| `未核实` | 查不到独立信源（多为小红书上的社群小活动） | 红字红边框 |

`未核实` 的条目**依然展示**，只是视觉上区分——这是产品的刻意选择，见功能文档。

## 已知的数据类型陷阱

Google Sheets 会把 `2026-09-02` 这样的字符串**自动识别成日期类型**，
`getValues()` 返回的是 JavaScript `Date` 对象而不是字符串。
`Code.gs` 里的 `cellToString_()` 负责统一转回 `yyyy-MM-dd` 字符串。
往 Sheet 里写数据时不用特殊处理，但**任何直接读 Sheet 的新代码都必须走 `cellToString_()`**。
